# Excel Dashboard Portfolio

This folder contains Excel-based dashboards with clean layouts, reusable calculations, and business-friendly insights. Each project should include the workbook, a short write-up, and a screenshot.

## Project Template

Use this structure for each Excel dashboard project:

```
Excel Dashboard/
  Project Name/
    data/ (raw and cleaned datasets)
    outputs/ (exports, charts, screenshots)
    Project_Name_Dashboard.xlsx
    README.md
```

### README Checklist

- **Business question**
- **Data sources & refresh cadence**
- **KPIs & definitions**
- **Key insights (plain language)**
- **Next steps / recommendations**

## Suggested Projects

1. **Sales Performance Tracker**
   - Monthly revenue, margin, and YoY growth.
2. **Inventory Health Dashboard**
   - Stockout risk, days of supply, reorder alerts.
3. **Financial Variance Analysis**
   - Actual vs. budget by department.

## Excel Best Practices

- Use **structured tables** and dynamic named ranges.
- Keep calculations in a **clean model sheet**.
- Use **consistent color palettes** and chart styles.
