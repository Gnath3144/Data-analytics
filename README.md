# Data Analytics Portfolio

Welcome! This repository is a curated portfolio of data analytics work across **Excel**, **Power BI**, **SQL**, and **Tableau**. Each folder contains a focused set of projects with clear business questions, datasets, analysis workflows, and dashboard deliverables.

## Recruiter Quick Start

- **Start here**: Review the `Projects` section below for end-to-end case studies.
- **Best artifacts**: Dashboards and SQL scripts live in their tool-specific folders.
- **Decision-ready insights**: Each project ends with a plain-language summary of business impact.

## Portfolio Highlights

- **Business-first storytelling**: every project starts with a business question and ends with actionable insights.
- **End-to-end analytics**: data preparation, analysis, visualization, and documentation.
- **Reproducible assets**: scripts, data dictionaries, and dashboard notes live alongside visuals.

## Skills & Tools

- **Analysis**: KPI design, funnel analysis, cohort analysis, segmentation, variance analysis
- **SQL**: joins, CTEs, window functions, data modeling, query optimization
- **Visualization**: dashboard UX, chart selection, drill-down workflows, executive summaries
- **Tools**: Excel, Power BI, Tableau, SQL (PostgreSQL/MySQL/SQL Server)

## End-to-End Projects (Case Studies)

These case studies are designed to mirror real business scenarios and demonstrate clear decision-making.

1. **Retail Performance Dashboard**
   - **Business question**: Which product categories and regions drive margin growth?
   - **Outcome**: Identify top 3 categories by margin and regions with declining profitability.
2. **Customer Retention & Cohorts**
   - **Business question**: Which acquisition channels retain customers the longest?
   - **Outcome**: Recommend budget shifts based on cohort retention.
3. **Marketing Funnel Optimization**
   - **Business question**: Where does the funnel lose the most qualified leads?
   - **Outcome**: Prioritize the stage with the highest conversion lift opportunity.
4. **Operations SLA Monitoring**
   - **Business question**: Which teams miss SLAs most frequently and why?
   - **Outcome**: Highlight workload bottlenecks and staffing needs.

## Portfolio Standards

- **Clarity**: Every README answers *what was analyzed*, *why it matters*, and *what to do next*.
- **Reproducibility**: Queries and calculations are documented and reusable.
- **Business impact**: Results are explained in plain language with recommended actions.
