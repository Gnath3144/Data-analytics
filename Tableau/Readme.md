# Tableau Portfolio

This folder contains Tableau dashboards and stories. Include packaged workbooks (`.twbx`), a README, and screenshots of key views.

## Project Template

```
Tableau/
  Project Name/
    data/ (raw and cleaned datasets)
    outputs/ (screenshots, exports)
    Project_Name.twbx
    README.md
```

### README Checklist

- **Business question**
- **Data sources**
- **Calculated fields**
- **Dashboard layout & interactions**
- **Insights & recommendations (plain language)**

## Suggested Projects

1. **Regional Sales Performance**
   - Map + trend dashboard with filters.
2. **Customer Support Analytics**
   - Ticket volume, resolution time, SLA compliance.
3. **Product Adoption**
   - Feature usage and activation cohorts.

## Tableau Best Practices

- Keep dashboards under 2–3 scrolls.
- Use consistent color palettes.
- Document calculated fields.
