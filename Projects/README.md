# Projects (Case Studies)

This folder hosts end-to-end analytics case studies that mirror real business scenarios. Each project includes a clear business question, documented analysis steps, and a plain-language summary of results.

## Standard Project Structure

```
Projects/
  Project-Name/
    data/ (raw and cleaned datasets)
    outputs/ (screenshots, exports, slides)
    README.md
    data_dictionary.md
```

## Case Study Checklist

- **Business question** (what decision are we enabling?)
- **Data sources** (tables, refresh cadence, limitations)
- **Methodology** (cleaning, modeling, metrics)
- **Key insights** (simple language + evidence)
- **Recommendations** (clear action items)
- **Next steps** (what to analyze next)
