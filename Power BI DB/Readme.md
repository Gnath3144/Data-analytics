# Power BI Portfolio

This folder is for Power BI reports, data models, and DAX measures. Include the `.pbix`, a README, and screenshots of key report pages.

## Project Template

```
Power BI DB/
  Project Name/
    data/ (raw and cleaned datasets)
    model/ (schema, data dictionary, measures)
    outputs/ (screenshots, exports)
    Project_Name.pbix
    README.md
```

### README Checklist

- **Business question**
- **Data model (facts/dimensions)**
- **DAX measures & KPIs**
- **Report pages and interactions**
- **Insights & recommendations (plain language)**

## Suggested Projects

1. **Executive KPI Scorecard**
   - Multi-page scorecard with trends and alerts.
2. **Customer Segmentation**
   - RFM scoring or clustering visuals.
3. **Marketing ROI Analysis**
   - Spend vs. revenue by channel and cohort.

## Power BI Best Practices

- Use **star schema** where possible.
- Create a **Measures table** for DAX.
- Keep visuals consistent and avoid clutter.
